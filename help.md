Line Editor Help

Commands

- "i" - Insert a line
- "d" - Delete a line
- "p" - Display the document
- "s" - Save the document
- "l" - Load the document
- "f" - Search for a word
- "w" - Count words
- "h" - Display help
- "q" - Quit

Example

Enter "i", then enter line number "1", then enter the text "Hello World".

Enter "p" to display the document.

Compile

gcc editor.c -o editor

Run

./editor
